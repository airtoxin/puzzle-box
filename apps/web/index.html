      現在の入力が正しいと仮定します。個数・行列ヒント・黒の非接触（10マス以下の行列で配置が8通り以下の場合を含む）・白2×2禁止・白連結の通路に限って調べます。白連結では入力済みの白をつなぐ必須通路と、候補配置で別の白から孤立する白を調べます。白を1つ以上にする条件だけからは推論しません。入力の正しさや、他のルールで進めるかは検証しません。

      同じ盤面とヒント、設定をURLに含めます。公開してよい内容だけ共有してください。途中の回答や答えは含まれません。開く際に唯一解を検証します。

      共有問題は唯一解を確認しますが、ヒントの既約性は再検証しないためJSON保存はできません。

      この実験でできること・できないこと
      • 対応する盤面とルールを読み込み中です。

      各盤面のカタログからルールとヒントを選びます。数字・部屋・丸などの指定欄は、必要とするルールを選ぶと表示されます。盤面の種類をまたぐ自由な混在、矢印配置の編集、自作Pythonのアップロードは未対応です。選べる組合せでも、条件の矛盾や計算予算により生成できない場合があります。

      唯一解とヒントの既約性は、人が推論だけで解けることや最小ヒント数を意味しません。答えは通常表示では隠しますが、ブラウザ内のデータと保存JSONには含まれます。

      計算予算にはワーカーの起動と検証を含みます。OSの起動・終了処理で指定秒数を超えることがあります。

      Puzzle Box · ルール定義の UI 宣言から構成する、ローカルの実験環境。
