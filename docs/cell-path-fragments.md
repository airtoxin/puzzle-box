# 同色の隣接数と端点数を組み合わせる

黒または白のマスを頂点とし、上下左右で接する同色の2マスを結ぶグラフとして扱う、2つの断片です。
斜めは隣接数に含めません。どちらも、それだけで1本の道を保証しません。

| 断片 | 条件 | 単独では許すもの |
| --- | --- | --- |
| `ColorDegreeRange(minimum=1, maximum=2, black=True)` | 対象色の各マスの同色隣接数を範囲内にする | 対象色0個、切り離された成分、閉路。`minimum=0` なら孤立も許す |
| `ColorEndpointCount(count=2, black=True)` | 対象色かつ同色隣接数がちょうど1のマスを、全盤面で指定個数にする | 枝分かれ、閉路、別成分、孤立。孤立マスは端点に数えない |

`black=False` は白を対象にします。反対色のマス自身の隣接数は制限・計数しません。
例えば孤立した黒1個の隣にある白マスは、黒の端点ではありません。

## 1本のセルの道にする

**同じ色について**、連結・各マスの隣接数1〜2・端点2個を組み合わせると、長さ2以上の枝分かれのない1本の道になります。
有限の連結グラフで各頂点の次数が1か2なら、道か閉路です。端点2個の条件で閉路を除きます。
これは黒白セルによる道で、線の辺を回答とするスリザーリンク等とは異なります。

```python
from puzzle_defs import ColorDegreeRange, ColorEndpointCount, ConnectedBlack, ShadingRecipe

recipe = ShadingRecipe(3, 3, (
    ConnectedBlack(), ColorDegreeRange(1, 2), ColorEndpointCount(2),
), ("cell", "row-count", "column-count"))
```

```sh
uv run --no-sync python examples/generate_shading.py generate --recipe examples/shading-cell-path-recipe.json --selection finite --seed 0 --output path.json --quiet
uv run --no-sync python examples/generate_shading.py show path.json
uv run --no-sync python examples/generate_shading.py verify path.json
```

[黒の3×3例](../examples/shading-cell-path-recipe.json)は、長さと端点の位置を固定せず、セル・行列の黒数ヒントを削減して一意にします。
必要なヒントは残り、最少ヒント数や人間の難易度を保証しません。黒の長さを固定したいときは `BlackCount(n)` を追加できます。
[白の2×3例](../examples/shading-white-path-recipe.json)では `ConnectedWhite()` と両断片の `black=False` を使います。
2断片の色を別々にした場合や、違う色を連結した場合は、それぞれ独立した条件であり、同じ道の保証にはなりません。

この合成は**斜めの接触を許します**。[Pentosnake の規則](https://www.gmpuzzles.com/blog/2017/06/pentosnake-nikolai-beluhov/)にも斜め接触を許す道が使われていますが、
ここでは頭尾の位置、文字、残りマスのペントミノを実装していません。斜め接触も禁止する別の Snake 規則や、Snake Pit の全盤面分割を実現したものでもありません。
道の端同士が斜めで接していても、上下左右の道として条件を満たせば許します。

## 条件を省いた場合

- 隣接数の上限がなければ、四角い閉路に2本の短い枝が付く配置も端点2個になり得ます。
- 端点数の条件がなければ、隣接数1〜2と連結だけでは全マスが隣接数2の閉路も残ります。
- 連結の条件がなければ、1本の道と別の閉路を同時に置ける場合があります。小盤面で置く余地がなくても、一般の盤面で連結を省いてよいことにはなりません。

T字は端点3個、閉路に枝1本を付けると端点1個になり得ます。端点数だけを指定する断片で、奇数を一律に拒否しません。
`ColorDegreeRange(0, 0)` は同色の辺接触禁止、`(1, 4)` は孤立禁止としても使えます。
`(2, 2)` は各対象色成分を閉路にし、対象色なしも許します。同色の非空連結を足せば、1つのセル閉路になります。
`(2, 2)` と正の端点数は矛盾します。閉路を描画する線入力は追加せず、回答は引き続き黒白セルです。

## Webと保存

黒の道の例では、既定の黒総数・白連結を外し、黒連結と「同色マスの隣接数を制限」「同色マスの端点数を固定」を有効にします。
隣接数1〜2・端点2・両方とも黒を選びます。白の道は白連結と、両方の色選択を白にします。
入力は既存の整数・真偽値、表示は黒白チャンネルなので、ルールのUI宣言だけで既存画面を使います。
プレビューが適合しても、個数や他の制約との両立は保証せず、生成で解なし・ヒント不足・打切りを区別します。

保存IDは `color-degree-range`（`minimum`, `maximum`, `black`）と `color-endpoint-count`（`count`, `black`）です。
最少・最多は厳密な整数で `0 <= minimum <= maximum <= 4`、端点数は非負整数かつ盤面のマス数以下、色は厳密な真偽値です。
真偽値を数値扱いせず、未知フィールド・意味を変え得るサブクラスを拒否します。データからコードは実行しません。
同じ型の複数出現はPython/保存形式で扱えますが、Webは既存どおり各IDを1回だけ選べます。

## 実装と限界

隣接数の範囲は、対象色のマスにだけ作用する線形条件です。端点は「対象色である」かつ「同色隣接数1」の双方向の条件で定めます。
端点の補助変数を偽にして個数を小さくしたり、反対色を端点として数えたりすることを防ぎます。補助変数は回答の射影に含めません。
個々のルールはヒントによらず固定され、生成時にヒントを削除しても条件は変わりません。

保存CLIは既存の25セル上限、Web・有限列挙は9セル上限と計算予算を維持します。通常CLIに壁時計の時間上限はありません。
2断片の説明推論は未対応で、その番号を報告します。唯一解や既約性は人が推測なしで解けることの証明ではありません。
検証は黒・白の全配置、方向ビットマスクと別の距離判定、セルの道を直接伸ばす独立探索、各条件を省いた反例を使います。
任意サイズや全組合せの性能を保証するものではありません。
