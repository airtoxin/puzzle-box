# 黒白ルールの盤面上限と拡張候補

黒白Webと保存形式全体は最大100セルです。選択したルールにより、より小さな上限が適用されます。有限全列挙による診断は独立の9セル上限です。黒白とループの複合盤面は9セル、スリザーリンクのWebは4セルまでで、黒白ルール固有の上限とは別です。上限は入力可能なサイズであり、計算予算内に生成できる保証ではありません。

## 改善したルール

- **成分サイズ固定**：以前は連結領域の候補を列挙したため9セル以下でした。現在は成分ラベルと深さが減る親辺を使い、盤面は100セル以下です。小盤面の全回答を独立した成分判定と比較しています。
- **同形テトロミノの部屋間接触禁止**：固定4セルの候補を列挙し、部屋境界に接する同形の候補を比較します。セルごとの配置索引を境界ごとに作り直さず共有するよう改善し、25セルから100セルまで拡張しました。黒マスが4個以外の部屋や斜め接触は、このルールでは禁止しません。
- **白の可視数**：各数字から四方向に向かう白の連続を、接頭部分ごとの補助変数で表します。全領域の列挙は不要です。100セル以下まで拡張しました。固定数字の値域は既存形式どおり0〜99で、可視数100は記録できません。ヒントの多い細長い盤面では補助変数が増え、時間内に解けないことがあります。

## 残る上限と拡張候補

| 上限 | ルール | 現在の方式と拡張時に必要なこと |
| --- | --- | --- |
| 9セル | 黒成分の面積合計、所属成分の面積、白い島の面積、数字がある白成分の面積 | 連結領域候補を列挙して成分を表すため、候補数は指数的。成分ラベルと成分面積を使う方式を検討できる。数字セルの色、数字0と数字なし、数字のない成分、同じ成分への複数接触を1回だけ数える意味を個別に保つ必要がある。 |
| 9セル | 部屋内の成分数固定、部屋内成分サイズの統一 | 部屋内の連結領域を列挙する。ラベル方式を部屋ごとに適用できるが、部屋外を通ってつながる成分を部屋内で統合しないこと、空・単一成分、部屋ごとに異なるサイズを検証する必要がある。 |
| 9セル | 角で接する成分の面積を異ならせる | 連結成分候補を列挙し、同面積で角接触する候補の組を禁止する。成分ラベルと面積に置き換える際は、同じ成分内部の角接触を許し、離れた同面積成分を禁止しないことが必要。 |
| 10セル | 各成分を別成分と角でつなぐ | 盤面の連結部分集合を列挙する。成分ラベルを使い各成分に別ラベルとの角接触があることを表せる可能性がある。空の色、同一成分内部の角接触、複数チェーンを検証する必要がある。 |

これらは設計候補であり、上限を変えれば安全に拡張できるという結論ではありません。変更する場合は小盤面の全黒白配置を独立実装と照合し、空集合・境界・複数成分・黒白の両方を含む反例を追加します。さらに保存形式の往復、Webの計画・生成・正誤確認、時間切れを未確定として扱うこと、実用サイズと最悪形状のモデル構築時間・メモリを測ります。補助変数を見える回答に数えないことも確認します。
