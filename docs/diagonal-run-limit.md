# 斜めの同色連続長

`DiagonalRunLimit(max_length=2)` は、右下・左下の直線に沿う黒・白それぞれの連続長を制限します。
縦横の条件は加えません。[縦横の連続長](run-length.md)や部屋・個数などと独立して組み合わせます。
1マスずつ進む45度の直線だけが対象で、曲がる経路、盤面端の折り返し、つながった成分全体の面積は数えません。

[ノンダンゴを定義した研究論文](https://arxiv.org/abs/2310.11447)の条件には、各部屋の黒丸1個と、縦横斜めの同色3連続禁止があります。
ここではその斜めの条件を再利用するために分離します。上限2で同色3連続を禁止し、上限1なら斜めに隣接する同色を禁止します。
既存の `NoThreeConsecutive()` と `RunLengthLimit()` は縦横だけで、保存ID・意味を変更しません。

## 空きマスのない3×3の組合せ

[保存レシピ](../examples/shading-diagonal-runs-recipe.json)では、全セルに黒白の選択肢がある盤面に次の3断片を使います。

```python
from puzzle_defs import (DiagonalRunLimit, NoThreeConsecutive,
                         RoomBlackCount, ShadingRecipe)

recipe = ShadingRecipe(3, 3, (
    RoomBlackCount(((0, 0, 1), (2, 1, 1), (2, 3, 3)), 1),
    NoThreeConsecutive(),
    DiagonalRunLimit(2),
))
```

最初の2条件では完成盤面が13個、斜め上限2を加えると6個です。ルールだけでは一意にならないため、生成時に必要なセルヒントを残します。
数字や部屋を自動生成する仕組みではありません。部屋配置・ルールは固定入力で、追加セルヒントを削減します。
各行全体を1部屋にして黒1個ずつに変更すると、縦横の条件では6個の完成盤面があっても、斜めを加えると矛盾します。
黒だけでなく白の3連続も禁止するためです。この不成立例も小盤面の全列挙で確認できます。

```sh
uv run --no-sync python examples/generate_shading.py generate --recipe examples/shading-diagonal-runs-recipe.json --selection finite --seed 0 --output diagonal.json --quiet
uv run --no-sync python examples/generate_shading.py show diagonal.json
uv run --no-sync python examples/generate_shading.py verify diagonal.json
```

`show` は部屋・固定ヒント・ルールと入力用の盤面を表示します。`--reveal` で答えを表示できます。保存JSON自体には完全解が含まれます。
固定seedは同じ環境での再実行に使い、環境・ソルバーの変更をまたぐ同一出力や、人間の難易度は保証しません。

## Webで選ぶ

[Webアプリ](web-app.md)の黒白セルを3行3列にし、初期の黒個数・白連結を外します。
「各部屋の黒数を固定」を選び、上の部屋配置と黒数1を設定します。
「同色の3連続を禁止」と「斜めの同色連続長を制限」を選び、斜めの上限を2にします。
ヒントはセルヒントを選び、行・列の黒数ヒントは外すと保存例と同じ設定になります。

宣言するパラメータは整数 `max_length`、必要な盤面は `answer/binary-cells` です。
既存の黒白セル・部屋境界・固定ヒントの表示と入力を使い、追加のJavaScript描画分岐はありません。
縦横と斜めを同時に選ぶ場合も、それぞれ別の数値欄で設定します。解答確認は両方の制約をサーバーで検査します。
例えば2×2で縦横・斜めを両方上限1にすると矛盾し、斜めだけ上限2に戻すと生成できます。

## 入力・互換性・限界

Pythonと保存形式の上限は厳密な正の整数で、真偽値・小数・文字列・0・負数を拒否します。
保存IDは `diagonal-run-limit`、必須フィールドは `max_length` だけで、未知・欠落フィールドや未知IDを拒否します。
ファイルからimportや任意コードを実行しません。旧読込器は新IDを拒否し、既存IDを別の意味にしません。
Webでは連続長の指定は1〜25、盤面は最大100セル・8ルールです。保存CLIも最大100セルです。
通常のPythonルールには盤面固有のセル上限を加えません。上限が盤面の短辺以上なら斜めの条件は冗長で、巨大な整数をソルバーへ渡しません。

全セルが黒白を選ぶ対象です。ノンダンゴの丸なしマスや、丸の位置を指定する入力・円形の描画は実装していません。
この例のセルは各位置の丸の色に相当する限定的な表現です。空きマスを白として代用すると斜めの条件が変わるため、同じパズルとは扱えません。
スリザーリンクやセル中心ループのプロファイルは新ルールを拒否します。専用の説明推論は未対応と報告します。
一意性・追加ヒントの既約性から、固定部屋の最小性や人が推測なしに解けることは導きません。

制約は長さ `max_length+1` の各斜め窓に両色を要求します。補助変数を加えず、解の射影は黒白セルです。
独立検査は盤面全体を斜めの不変量で分類し、別の参照検査は端から直線を歩いて同色区間の長さを測ります。
1次元・長方形・3×3の小盤面で、両方向・両色・境界・冗長な上限をCSPの全完成集合と照合します。
これらは有限範囲の検証であり、任意のサイズや全組合せの性能・成功率の保証ではありません。
